❓ Como usar o Dashboard

[UL] Dashboard_Taxonomias · Unilever BR · Grasp x StormX

📌 Hierarquia dos dados
Os tickets são agrupados em 4 níveis:
BU → Agência → Marca → Campanha
Dentro de cada campanha aparecem os tickets filhos com veículo, ação, status e campos do Jira.
🔍 Filtros
Refine por BU, Agência, Marca, Campanha, Filho, Veículo, Status ADP, Plataforma ou Status.
Clique nos cards de KPI para filtrar rapidamente por status.
📅 Filtro de data
Local (rápido): filtra os dados já carregados — instantâneo.
Rebuscar Jira: recarrega buscando o período direto no Jira.
⚠️ Não mapeado
O termo do título da issue não está no dicionário.

🔢 Por que o total difere do Jira?
O Jira conta todas as issues (pais + filhos + inválidos). O dashboard conta só o trabalho executável:

■ Tickets de trabalho — subtarefas + tickets solo (sem filhos).
■ Campanhas — tarefas pai que têm subtarefas. São agrupadores.
■ Incorretos — issues com tipo inválido. Visíveis no banner ⚠️.

O Jira conta todas as issues independente de tipo ou relação. O dashboard conta só o trabalho executável:

■ Subtarefas — tickets com pai (trabalho real).
■ Solos — tarefas sem subtarefas (também são trabalho).
■ Pais — tarefas com subtarefas. São agrupadores, não entram no total.
■ Incorretos — tipos inválidos (Epic, Bug etc). Aparecem em banner vermelho.

Jira = Pais + Subtarefas + Solos + Incorretos
Dashboard = Subtarefas + Solos
Tickets com múltiplos veículos aparecem em mais de uma linha mas são contados uma vez só nos KPIs.
🔗 Links de ticket
Badges azuis como UL-4598 abrem o ticket diretamente no Jira em nova aba.
